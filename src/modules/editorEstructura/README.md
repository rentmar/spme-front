# Módulo editorEstructura

Este modulo gestiona toda la logica relacionada a la creacion de la estructura de los proyectos por nodos. La creacion de los nodos, la edicion de su informacion.

### Componentes

- **`EditorEstructuraMain.vue`**: El Componente principal del editor.
  nodos - Carpeta con todos los nodos personalizados
  nodosFormularios - Carpeta con formularios para editar los nodos personalizados
